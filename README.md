# Dev HUB SENATI

Plataforma web que reúne y clasifica recursos tecnológicos para estudiantes de SENATI.

## Características

- Página de inicio
- Catálogo de recursos tecnológicos (mínimo 6)
- Buscador funcional
- Filtros por categorías
- Diseño responsive
- Botones interactivos
- Sección de integrantes

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Git y GitHub

## Estructura del proyecto

```
dev-hub-senati/
├── index.html      → Página principal
├── css/
│   └── styles.css  → Estilos y diseño responsive
├── js/
│   └── app.js      → Catálogo, buscador y filtros
└── README.md
```

## Integrantes

| Integrante | Rol |
|---|---|
| Integrante 1 | HTML, CSS y diseño responsive |
| Integrante 2 | JavaScript, catálogo, buscador y filtros |

## Flujo de trabajo colaborativo

1. Cada integrante trabaja en su propia rama:
   - `feature/integrante1-html-css`
   - `feature/integrante2-js-catalogo`
2. Se abre un Pull Request por rama hacia `main`.
3. Tras la revisión, se hace merge en `main`.
